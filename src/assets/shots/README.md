# Project screenshots

Drop a picture of each site in this folder and it replaces the wireframe in that project's card.

| File name (any of .jpg .jpeg .png .webp .avif) | Project               |
| ---------------------------------------------- | --------------------- |
| `st-anthonys.webp`                             | St. Anthony's Service |
| `purehydro.webp`                               | Purehydro             |
| `fletching.webp`                               | Fletching Logistics   |
| `willpower.webp`                               | WillPower Alliance    |

Tips:

- Use the whole home page as one tall picture (a full-page screenshot). The card shows the top of it,
  and on hover the page scrolls down slowly and back up like a preview. How far and how fast is worked
  out from the picture's height, so any length works.
- About 1440 px wide gives a sharp result. Export as `.webp` or an optimised `.jpg` to keep the page
  fast (these four are about 100 to 190 KB each).
- The file name is matched to the `slug` of each project in `src/data/work.js`.
