# Project screenshots

Drop a picture of each site in this folder and it replaces the wireframe in that project's card.

| File name (any of .jpg .jpeg .png .webp .avif) | Project |
| --- | --- |
| `st-anthonys.jpg` | St. Anthony's Service |
| `purehydro.jpg` | Purehydro |
| `willpower.jpg` | WillPower Alliance |

Tips:

- Capture the top of the home page in a browser window about 1600 px wide. The frame shows a 16:10
  crop aligned to the top, so anything below the first screen is cut off.
- Export as `.webp` or an optimised `.jpg` (under about 250 KB) to keep the page fast.
- The file name is matched to the `slug` of each project in `src/data/work.js`.
